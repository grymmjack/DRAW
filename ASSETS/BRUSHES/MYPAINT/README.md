# MyPaint brushes

The brush sets from [mypaint-brushes](https://github.com/mypaint/mypaint-brushes)
(commit 08da4a48, 2021-04-02). Every brush setting file (`.myb`) and preview (`_prev.png`)
here is released under **CC0 1.0** (public domain) - see `COPYING-CC0` and the upstream
`Licenses.dep5`. DRAW paints them with libmypaint (ISC, `native/mypaint/`).

| Folder | Author |
| --- | --- |
| classic, experimental | Martin Renold and the MyPaint Development Team |
| deevad | David Revoy |
| Dieterle | Brien Dieterle |
| kaerhon_v1 | Guillaume Loussarévian |
| ramon | Ramón Miranda |
| tanda | Marcelo "Tanda" Cerviño |

`order.conf` is MyPaint's grouping and order, which DRAW's brush palette follows.
Your own brushes (saved from DRAW, or copied from MyPaint / Krita) go in DRAW's data folder,
`MYPAINT-BRUSHES/` (`DRAW.run --dirs`).
