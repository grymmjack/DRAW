# Command icons

Art for commands placed on the toolbox, edit bar or advanced bar with
**View → Customize Toolbars**. A command that has no icon shows a text tile
(up to 3 letters of its name) until its file is here.

| File | Size | Used for |
| --- | --- | --- |
| `COMMANDS/<name>.png` | 16×16 RGBA | the edit bar / advanced bar, the editor's lists, and toolbox cells when there is no 11×11 version |
| `COMMANDS/TOOLBOX/<name>.png` | 11×11 RGBA, optional | toolbox cells, drawn at the toolbox's scale like the tool buttons |

`<name>` is the command's name in lower case with words joined by `-`
(**New Layer** → `new-layer.png`). `cmd-<action id>.png` works too. DRAW
looks in the active theme's `IMAGES/COMMANDS/` first, then in `DEFAULT`'s.
The dimmed (disabled) look is made automatically.

The work list (every command, its file name, whether it has art yet) is
`PLANS/_/COMMAND-ICONS.csv`, regenerated by `DEV/tools/command-icons.py`.
Commands that already have a bar icon (`IMAGES/EDITBAR`, `IMAGES/ADVANCEDBAR`)
keep it; a file here is only used for commands without one.
