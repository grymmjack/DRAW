# ================================================================= History ====

[view-history-show-hide]
about: a clock - shows / hides the History palette (the list of every undo step)
use: @panels-clock

[edit-clear-history]
about: the history clock + an x - clear the history (forget every undo step)
use: @panels-clock
badge: @b-x

# ================================================================= Actions ====

[view-actions-show-hide]
about: the Actions list (rows, each with a play triangle) - shows / hides the Actions palette
use: @panels-actions

[actions-record]
about: the Actions list + a record dot - record into the selected action
use: @panels-actions
badge: @panels-b-rec

[actions-stop-recording]
about: the Actions list + a stop square - stop recording
use: @panels-actions
badge: @panels-b-stop

[actions-play-selection]
about: the Actions list + a play triangle - play the selected action / steps
use: @panels-actions
badge: @b-play

[actions-new-set]
about: a folder holding a play triangle + a plus - a new action set
use: @panels-actions-set
badge: @b-plus

[actions-new-action-records]
about: the Actions list + a plus - a new action (it starts recording)
use: @panels-actions
badge: @b-plus

[actions-delete-selection]
about: the Actions list + an x - delete the selected actions / steps
use: @panels-actions
badge: @b-x

[actions-insert-stop]
about: the Actions list + pause bars - insert a stop (playback halts there until you go on)
use: @panels-actions
badge: @layer-color-b-pause
