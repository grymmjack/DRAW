# Command button glyphs - group: edit-anim (animation editing: frames, X-sheet keys,
# tags + notes, holds, linked cells, sound tracks, AnimBrush, Move Brush, AnimPaint)
#
# Families (keep them together):
#   @frame / @frames   a frame cell / a strip of them; the badge says what happens to it
#   @key               X-sheet keys
#   @speaker           a sound clip;  @edit-anim-track  a sound track (a lane with a wave)
#   @edit-anim-b-copy / -b-cut / -b-paste   copy / cut / paste, stamped on any of the above
#   @edit-anim-move    Move Brush: a brush stamp, a dotted path, an arrow head
#   @edit-anim-animbrush   AnimBrush: a brush over a film strip
