# Command button glyphs - group: view-ui (showing / hiding / docking the UI, workspaces,
# zoom, display scale, panning, theme, canvas border, full screen, CRT effect, crosshair,
# angle snap). See DEV/tools/make-command-icons.py for the format.
#
# Families:
#   layout diagrams   a window with one part of DRAW's UI filled (menu bar, status bar,
#                     left / right side, all of it)
#   dock left / right @dock-left-style window + the panel's letter (T L E A)
#   panels            the panel's own look (toolbox, layer rows, organizer, drawer, bars)
#   workspace         a window split into panes (@view-ui-workspace) + a badge
#   zoom              @magnifier with + / - / 1 in the lens
#   display scale     @monitor with + / - / turn arrow on the screen
#   CRT               a round-cornered tube (@view-ui-crt) with what each switch adds
