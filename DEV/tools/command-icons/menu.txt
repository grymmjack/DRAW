# Command button glyphs - group "menu": commands that live only in the menus
# (File / Edit / Palette / AI / Help / Audio). Pictures reuse 00-pieces.txt;
# group-only pieces are named [@menu-*].
#
# Families:
#   AI         = @sparkle (+ badge: plus new, refresh regenerate, x cancel, gear tools)
#                style / prompt editors = brush / speech bubble + a small AI twinkle
#   Palette    = @swatches (+ in / out arrows), Lospec = a globe (the web)
#   Help       = "?" box, "i" circle, keyboard, book, branch, bug, people
#   Crash logs = a warning triangle (folder with "!" for the folder)
#   Sound FX   = speaker, Music = note; +, -, x signs to their right
#   Tracks     = media skip symbols
