# Command button glyphs - group: file (File menu: new / open / save / revert / exit,
# imports and exports, drawer sets, kits, templates, animation exports).
# Spec format: see DEV/tools/make-command-icons.py. Shared pieces: 00-pieces.txt.
#
# Families:
#   open = an open folder (@file-open), save = a floppy (@file-floppy),
#   a .draw project = those + a layer diamond badge (@file-b-layer),
#   exports = a picture with an arrow leaving it (@b-out), imports = an arrow arriving (@b-in);
#   a FORMAT export puts the format below a small picture + arrow at 16px (PNG, GIF, BAS...),
#   at 11px two letters under the arrow (or the picture with one letter when the picture
#   tells the family: frames, grid, colour cycle).
#   drawer sets = a chest of drawers (@file-drawer), kits = a toolbox case (@file-kit).
